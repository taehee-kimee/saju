## 🎯 핵심 가치 제안 (Value Proposition)

### "과학(MBTI) + 전통(사주)의 만남"
- MBTI 성격유형과 동양 철학의 오행(五行)을 결합한 **독자적 알고리즘**
- 20가지 고양이 캐릭터로 **직관적이고 친근한 결과** 제공
- 기본 결과는 **묵과 상세 분석은 유료**로 전환율 극대화

## 🎮 기능 상세

### 1. 홈 페이지 (`/`)
- **목적**: 서비스 소개 및 진입점
- **구성**:
  - 로고 + 슬로건 (🐱 냥세 · 고양이 운영 분석)
  - 핵심 기능 태그 (🌿 오행 분석 · ✨ MBTI 매핑 · 🐱 20종 캐릭터)
  - CTA 버튼: "내 고양이 찾기 →"
  - 가격 정보: "기본 결과 묶 · 상세 리포트 990원"

### 2. MBTI 입력 (`/test`)
- **3가지 모드**:
  1. **선택 모드**: MBTI를 알고 있는지 질문
  2. **직접 입력**: 4글자 직접 입력 (예: INFP)
  3. **테스트 모드**: 12문항 테스트

- **테스트 문항 구성**:
  | 번호 | 영역 | 질문 예시 |
  |------|------|----------|
  | 1-3 | E/I | "새로운 사람과 있으면 에너지가 충전/소모" |
  | 4-6 | S/N | "사실 중심 vs 가능성 중심" |
  | 7-9 | T/F | "논리 vs 감정" |
  | 10-12 | J/P | "계획 vs 유연" |

- **결과 처리**: sessionStorage에 `mbti` 저장 → `/saju` 이동

### 3. 사주 입력 (`/saju`)
- **입력 항목**:
  - 출생 연도 (4자리)
  - 출생 월 (1-12)
  - 출생 일 (1-31)
  - 출생 시간 (0-23시, 선택사항 - 기본값: 12시/모름)

- **처리 로직**:
  ```typescript
  lunisolar(date).char8  // 사주팔자 계산
  // 年柱, 月柱, 日柱, 時柱
  // 천간(天干) + 지지(地支) → 오행 매핑
  ```

- **오행 계산**:
  - 천간(甲,乙,丙,丁,戊,己,庚,辛,壬,癸) → 木,火,土,金,水
  - 지지(子,丑,寅,卯,辰,巳,午,未,申,酉,戌,亥) → 水,土,木,木,土,火,火,土,金,金,土,水
  - 8글자의 오행 분포 분석 → 지배 오행 결정

### 4. 결과 페이지 (`/result`)
- **표시 정보**:
  - 고양이 캐릭터 (이미지, 이름, 외모, 태그라인)
  - 짧은 설명 (shortDesc)
  - 오행 에너지 바 차트
  - 광고 슬롯

- **액션**:
  - "상세 분석 보기 · 990원" 버튼 → `/report` 이동
  - 공유 카드 다운로드 (이미지)

### 5. 상세 리포트 (`/report`)
- **묶 버전**:
  - 상세 분석 티저
  - 결제 CTA

- **유료 버전** (결제 후):
  - 상세 성격 분석 (fullDesc)
  - 2026년 운세 (yearFortune)
  - 이달의 운세 (동적 현재 월)
  - 12개월 월별 운세

- **결제 시스템**:
  - Toss Payments 연동
  - 금액: 990원
  - 성공 시 `paymentKey`, `orderId`로 검증 → 콘텐츠 해금
  - Debug 모드 지원 (`?debug=true`)

## 🐱 캐릭터 시스템

| **NT** (直観-思考) | 🔍 탐정냥 | 😤 보스냥 | 🤔 철학냥 | 🧊 냉미남냥 | 🌑 음모냥 |
| **NF** (直観-感情) | 🌙 새벽냥 | 🌟 열정냥 | 🫂 공감냥 | 🤍 순백냥 | 🔮 신비냥 |
| **ST** (感覚-思考) | 📋 성실냥 | 💥 돌격냥 | 🏠 든든냥 | 📐 완벽냥 | 🧘 침착냥 |
| **SF** (感覚-感情) | ☀️ 따뜻냥 | 🎉 인싸냥 | 🍵 집사냥 | 🎀 섬세냥 | 💙 치유냥 |

### 캐릭터 데이터 구조
```typescript
interface CatCharacter {
  id: CatId;           // "NT_木", "SF_水" 등
  name: string;        // 캐릭터명
  emoji: string;       // 이모지
  appearance: string;  // 외모 설명
  tagline: string;     // 한 줄 태그

}
```

## 📝 메모

> **냥세**는 "고양이의 세상"이라는 의미입니다.  
> 동양 철학의 오행(五行)과 서양 심리학의 MBTI를 결합하여  
> 현대적인 방식으로 전통 운세를 재해석한 서비스입니다.

**강점**:
- 친근한 고양이 캐릭터로 진입장벽 낮춤
- MBTI와 사주라는 검증된 콘텐츠의 결합
- 간단한 입력으로 즉각적인 결과 제공
- 공유하기 좋은 비주얼 결과물

**개선 포인트**:
- 테스트 문항 수 증가 시 정확도 향상 (현재 12개 → 28개 권장)
- 사용자 로그인/결제 이력 관리
- A/B 테스트로 최적의 가격 책정
