## 작성할 섹션 (4개)

### 1. diagnosis (냥세 한 줄 진단)
**목적:** 캐릭터의 핵심 특성을 한 문단으로 요약

**작성 가이드:**
- 200-300자 (한글 기준)
- 이 캐릭터의 **가장 두드러진 특성** 2-3가지 중심
- 긍정적 표현 위주, 단점은 부드럽게
- 독자가 "아 이게 나야"라고 느끼도록 구체적 묘사
- 이모지 활용 (1-2개)

**구조:**
```
[핵심 특성 소개] + [구체적 행동/사고 방식] + [주변의 반응] + [한 줄 조언]
```

**예시 (탐정냥):**
```
조용히 관찰하며 혼자만의 세계에서 모든 것을 분석하는 당신. 남들이 눈치채기도 전에 상황의 전말을 파악하고 있으며, 끝없는 '왜?'라는 질문으로 진실을 파헤칩니다. 겉으로는 차분해 보이지만, 머릿속은 늘 복잡한 퍼즐을 푸는 데 몰두하고 있죠. 완벽한 정보를 얻기 위해 계속 조사하고 분석하다가 결국 행동을 미루는 경향이 있어요. 때로는 분석하느라 기회를 놓치기도 하지만, 한번 결정하면 철저한 계획으로 완성핸내는 당신의 능력은 탁월합니다. 주변 사람들은 당신의 날카로운 통찰력에 놀라며, 종종 '어떻게 그걸 알았어?'라는 반응을 보이죠.
```

### 2. ohaengMap (오행 밸런스 지도)
**목적:** 해당 오행(목화토금수)이 캐릭터에게 주는 영향 설명

**작성 가이드:**
- 200-300자
- 해당 오행의 **상징적 의미** 연결
- 오행 특성 + MBTI 특성의 시너지 설명
- 2026년 운세 힌트 (1-2문장)
- 독자가共感할 수 있는 비유 사용

**오행별 키워드 참고:**
- 木(목): 성장, 확장, 유연성, 봄, 발전
- 火(화): 열정, 활력, 추진력, 여름, 변화
- 土(토): 안정, 포용력, 신뢰, 늦여름, 기초
- 金(금): 정돈, 완성, 질서, 가을, 정확성
- 水(수): 유연함, 지혜, 깊이, 겨울, 적응력

**구조:**
```
[오행의 상징적 의미] + [캐릭터와의 연결] + [강점] + [주의점] + [2026년 운세]
```

**예시 (탐정냥 - 木):**
```
목(木)의 기운은 성장과 확장을 상징합니다. 분석력과 함께 끊임없이 성장하려는 욕구가 당신 안에 살아있죠. 나무가 뿌리를 깊이 내리고 하늘로 뻗어가듯, 당신도 지식과 이해의 깊이를 추구합니다. 하지만 나무가 가만히 서서 주변을 지켜보듯, 지나친 관찰로 행동이 늦어지는 경향이 있어요. 목의 에너지는 당신에게 유연성과 적응력을 주지만, 때로는 뿌리째 뽑혀버릴까봐 변화를 두려워하기도 합니다. 2026년에는 당신의 분석력이 빛을 발할 해입니다. 새로운 분야에 도전하거나 깊이 있는 학습을 시작하기에 좋은 시기죠.
```

### 3. mbtiEngine (MBTI 행동 엔진)
**목적:** MBTI 유형의 심리적 메커니즘 설명

**작성 가이드:**
- 200-300자
- MBTI 4가지 지표 중 **가운데 2글자(직관/감각 + 사고/감정)** 중심
- I/E, J/P는 언급하되 가볍게
- **'왜 이런 행동을 하는가'**에 대한 심리적 설명
- 전문적이지만 이해하기 쉽게

**구조:**
```
[MBTI 조합 설명] + [핵심 심리 메커니즘] + [생각/행동 패턴] + [강점과 약점] + [타인과의 차이점]
```

**예시 (탐정냥 - INTJ/INTP):**
```
INTJ와 INTP의 직관(N)과 사고(T)가 결합한 당신은 '왜?'를 끝까지 파고드는 탐구자입니다. 겉으로 보이는 현상뿐 아니라 그 이면의 원리와 구조를 이해하려 노력하죠. 감정보다 논리와 객관적인 사실을 우선시하며, 완벽한 정보를 원해 결정을 미루기도 합니다. 당신의 머릿속은 늘 복잡한 시스템과 아이디어로 가득 차 있으며, 혼자만의 시간을 통해 이를 정리하고 발전시킵니다. 타인의 감정을 읽는 데 어려움을 겪을 수 있지만, 한번 친해진 사람에게는 깊은 충성심을 보입니다. 전략적 사고와 장기적인 계획 수립 능력이 당신의 강점입니다.
```

### 4. combination (사주×MBTI 결합 해석)
**목적:** 오행과 MBTI가 결합되어 만들어내는 고유한 시너지 설명

**작성 가이드:**
- 200-300자
- **오행 에너지 + MBTI 특성**의 조합 결과
- "이 조합이 만들어내는 독특한 사람" 설명
- 장점과 주의할 점 균형있게
- 2026년 조언 (1-2문장)

**구조:**
```
[조합의 결과: XX한 XX] + [시너지 설명] + [강점] + [약점/보완점] + [2026년 조언]
```

**예시 (탐정냥 - 木+NT):**
```
목(木)의 성장 욕구와 NT의 전략적 사고가 만나 '더 나은 방법을 찾는 탐구자'가 되었습니다. 당신은 현재 상황을 분석하고 미래를 예측하는 데 탁월한 능력을 가졌죠. 하지만 현실적인 실행력이 부족할 수 있어, 머릿속의 완벽한 계획을 실제로 옮기는 데 어려움을 겪기도 합니다. 2026년에는 당신의 아이디어가 현실이 될 수 있습니다. 작은 것부터 시작해 점진적으로 실행핸내는 연습을 항보세요. 당신의 통찰력이 세상에 가치를 더하는 한 해가 될 것입니다. 때로는 완벽하지 않아도 괜찮다는 것을 받아들이는 것이 성장의 열쇠입니다.
```
