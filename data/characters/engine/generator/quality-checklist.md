# Free Report QC Checklist

## 구조
- [ ] 섹션 5개 순서 고정인가?
- [ ] 분량이 섹션별 최소치(800) 충족인가?
- [ ] diagnosis에 기능 스택 + 4기능 질문 포함인가?

## 분화
- [ ] ohaengMap에서 MBTI 기능 설명을 반복하지 않았는가?
- [ ] combination에서 conflict_map 키워드가 실제로 해석되었는가?
- [ ] 붕괴 루프가 4~5단계로 명확한가?

## 공감도 ("오 맞아")
- [ ] 체감 묘사(비유/감각 표현)가 1~2개 있는가?
- [ ] 외부에서 보이는 모습 vs 내부 체감 대비가 있는가?
- [ ] 자기 의심 문장이 1개 이상 있는가?

## 안전/금지
- [ ] 예언/연도/확정 표현이 없는가?
- [ ] 불안 조장(죄책감/공포/의존 유도)이 없는가?
- [ ] 오행 키워드 반복으로 끝나지 않는가?
